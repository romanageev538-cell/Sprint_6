# QA Java Project

Учебный проект по модульному тестированию Java-кода с измерением покрытия.

## Исследуемый набор данных

В проекте моделируется простая иерархия классов животных:

- **`Animal`** — базовый класс с методами `getFood(String)` (возвращает рацион для «Травоядное»/«Хищник» или выбрасывает исключение) и `getFamily()`.
- **`Predator`** — интерфейс с методом `eatMeat()`.
- **`Feline`** — наследует `Animal`, реализует `Predator`; переопределяет `eatMeat()` и `getFamily()`, добавляет методы `getKittens()` и `getKittens(int)`.
- **`Cat`** — содержит ссылку на `Predator`, методы `getSound()` и `getFood()`.
- **`Lion`** — содержит `Feline`; конструктор принимает пол («Самец»/«Самка») и выбрасывает исключение при неверном значении; методы `getKittens()`, `doesHaveMane()`, `getFood()`.

## Цели исследования

- Написание модульных тестов для проверки корректности методов, обработки исключений и наследования.
- Использование параметризованных тестов (для количества котят у `Feline` и наличия гривы у `Lion` в зависимости от пола).
- Применение моков (Mockito) для изоляции зависимостей (`Cat` и `Lion` от `Feline`).
- Измерение покрытия кода с помощью JaCoCo.

## Используемые библиотеки

- **JUnit 4.13.2** — фреймворк модульного тестирования.
- **Mockito 5.23.0** — создание мок-объектов.
- **JaCoCo Maven Plugin 0.8.14** — анализ покрытия кода.
